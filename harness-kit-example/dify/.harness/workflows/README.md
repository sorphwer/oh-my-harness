# Workflow Index

Workflows are ordered phase checklists. Each selected workflow also has a dedicated file in this
directory.

- Brainstorm: establish the affected Pyrefly architecture phase and the user-visible behavior.
- Plan: choose the narrow implementation and verification commands.
- Implement: make the minimal code and test changes.
- Test: run targeted tests plus required formatting/linting.
- Review: summarize risk, behavior, and evidence.
- Record: update harness or project history only when useful.
