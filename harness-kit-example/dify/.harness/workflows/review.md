# Review Workflow

Phase: review

Entry criteria:
- Targeted tests and formatting/linting have been attempted.

Exit criteria:
- Review-ready summary with behavior, files, and verification.

Checklist:
- Lead with user-visible behavior or type-checker semantics, not a file-by-file
  implementation list.
- Call out test coverage and any command that could not be run.
- Mention generated files only when they changed intentionally.
- For review requests, prioritize findings by severity with file and line
  references.
