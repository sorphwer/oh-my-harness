# frontend

Building, polishing, and auditing user-facing web surfaces.

## Contributes

- `skills/frontend-implementation` — build the real working screen first, matching app density and using existing primitives.
- `skills/frontend-polish` — visual and interaction polish once the surface works.
- `skills/accessibility-audit` — review against WCAG/keyboard/focus/contrast expectations.

## When to include

Any project with a web UI (Next.js, React, SvelteKit, etc.). Skip for pure CLI / backend services.
