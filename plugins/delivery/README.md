# delivery

Code review, verification, and the discipline of finishing a branch.

## Contributes

- `skills/code-review` — review a diff/PR for bugs, regressions, missing tests, security impact.
- `skills/requesting-code-review` — prepare a change so a reviewer can be effective.
- `skills/receiving-code-review` — incorporate review feedback without losing context.
- `skills/verification-before-completion` — prove the change works (execution, not inspection) before declaring done.
- `skills/finishing-branch` — final checks, cleanup, and merge readiness.

## When to include

Default for every project with more than one contributor or any branch-based workflow.
