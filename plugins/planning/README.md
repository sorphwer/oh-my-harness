# planning

Intent capture, design specs, implementation plans, and TDD-style execution.

## Contributes

- `skills/brainstorming` — turn a vague idea into a written design spec via dialogue.
- `skills/spec-first-planning` — convert an approved spec into a bite-sized implementation plan.
- `skills/test-driven-development` — red/green/refactor discipline for executing plan tasks.

## When to include

Default for any project where work flows spec → plan → code. Pair with `delivery` for review and shipping discipline.
